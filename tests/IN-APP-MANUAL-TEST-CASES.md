# 应用内用户手册 测试用例

覆盖范围：手册**随包发布**、**应用内手册窗**（帮助 → 用户手册 / `F1`）、**agent 的 `get_manual` 工具**。
只测这三件事受影响的范围；手册正文的内容准确性不在此列（那靠 review），插图生成见
`tools/ScreenshotBot/README.md`。

自动化部分已在 `tests/TuneLab.Tests/ManualLibraryTests.cs`（13 条）：章节切分、稳定 id、标题去章号、
`Find` 三种命中（id / 标题 / 子节）、`ForModel` 剥插图与注释、目录、检索。以下是需要人在界面里看的部分。

## 前置

1. `dotnet build TuneLab.sln -c Debug`
2. 运行 `TuneLab/bin/Debug/net8.0/TuneLab.exe`
3. 界面语言默认（中文）；测 A-5 时再改语言
4. 测 C 组需要在 Agent 页配好一个可用模型

---

## A. 随包与手册窗

| # | 操作 | 期望 |
|---|------|------|
| A-1 | 看 `TuneLab/bin/Debug/net8.0/Resources/Manual/` | 有 `zh-CN.md`，且 `images/manual/` 下 26 张 png。**仓库 `TuneLab/Resources/` 下不该出现 Manual 目录**（那说明留了副本、真相源分叉） |
| A-2 | 菜单 **帮助** | 首项是「用户手册」，右侧显示手势 `F1` |
| A-3 | 点「用户手册」 | 开出独立窗口：左侧 17 章目录、右侧**一整页**正文（不是按章分页）；标题栏居中写「用户手册」 |
| A-4 | 从头滚到尾 | 全篇都能渲染：标题、表格、行内代码、链接、**插图**；滚动时左侧高亮跟着走（scroll-spy） |
| A-4b | 点目录里**很远**的一条 | 一条连续的滚动：先加速掠过长途段（跳得越远掠得越快），最后 240px 减速到位——**没有瞬移**，也不是全程匀速补间。章标题落在视口顶端；该条当场高亮（动画途中不闪过别的章） |
| A-4b3 | 点**相邻**的一条（距离不足 240px） | 直接从当前位置起跑，不先跳开 |
| A-4b4 | 点最后一条 | 钳到底部，不出现"点了没反应" |
| A-4b2 | 点目录后动画途中立刻滚滚轮 | 动画让位给用户，不再把画面拽回目标处；高亮改为跟随实际滚动位置 |
| A-4f | 拖右侧滚动条手柄，尤其贴近窗口右边界处 | 拖的是内容而不是窗口宽度（手柄离右边界约 10px，让开无边框窗的 resize 命中区）；拖到窗口最右缘才是 resize |
| A-4c | 看任一插图 | 有一圈细边框把图与页面背景分开（软件自身截图与页面同配色，无边框会认不出边界） |
| A-4d | 点插图 | 弹出放大浮层：图按视口缩放装下（大图不再只看见左上角）、显示的是**原分辨率**的图；滚轮以光标为锚缩放、左/中键拖动平移、点任意处或 `Esc` 关闭 |
| A-4e | 放大浮层开着时再点别的图 | 只留一个浮层（替换并复位缩放/平移） |
| A-5 | 改界面语言为 English 并重启，再开手册窗 | 仍打开（回退到 `zh-CN` 版），且正文上方有一行说明「暂无当前语言版本，显示的是 zh-CN 版」 |
| A-6 | 按 `F1` | 打开手册窗；**再按一次 / 再点菜单** → 不叠出第二个窗，而是把已开的窗激活到前面 |
| A-6b | 关掉手册窗再打开 | **秒开**（整页控件与已解码插图跨窗复用；首次打开约半秒是渲染整篇的成本）。复用后插图、跳转、放大都仍正常 |
| A-6c | 关掉手册窗，再关主窗 | 进程正常退出（缓存的是内容不是窗口，故不会留一个隐藏窗让"最后一个窗关了"判不出来） |
| A-7 | 在钢琴窗里按 `F1`、在编排区按 `F1` | 都能打开（该命令是 Global 作用域） |
| A-8 | 手册窗内拖动顶栏空白处 / 点右上关闭键 | 能移窗；关闭键按下后拖走再松手**不**关闭（按钮语义） |
| A-9 | 拖窄手册窗到最小宽度 | 表格与正文按视口换行，**不出现横向滚动条**；左侧目录出现浮层竖向滚动条 |
| A-10 | 设置 → 快捷键页搜索「手册」 | 有「用户手册」一条，可改绑、可解绑；解绑后 `F1` 不再触发、菜单项手势变空 |

## B. 与生成物的一致性

| # | 操作 | 期望 |
|---|------|------|
| B-1 | 改 `docs/user-manual.zh-CN.md` 里某章标题 → 重新构建 → 开手册窗 | 左侧目录随之变（证明窗读的就是 docs 那一份，不是副本） |
| B-2 | 删掉某章前的 `<!-- section: id -->` 注释 → `dotnet test` | `ManualLibraryTests` 失败（哨兵生效），而不是静默退化成 slug id |
| B-3 | `pwsh tools/ScreenshotBot/shoot.ps1` | `docs/generated/keybindings.md` 里出现 `app.manual` / `F1` 一行 |

## C. agent 用手册答用法问题

| # | 提问 | 期望 |
|---|------|------|
| C-1 | 「颤音怎么画？」 | 调 `get_manual`（先目录或直接 `section`/`query`），答案与手册「钢琴窗：音高与颤音」一节一致（颤音工具、悬停预览、拖两端/幅度/频率/相位柄），**不是**泛泛而谈的通用 DAW 说法 |
| C-2 | 「导出选区在哪设置？」 | 调 `get_manual`，答出侧栏导出页的「导出范围 = 选区」，并指出选区来自编排区 `Shift`+拖 |
| C-3 | 「固定笔刷是干什么的？」 | 答出「把引擎合成的音高固定成可编辑的用户曲线；右键擦除」 |
| C-4 | 「我的颤音工具快捷键现在是什么？」 | 走 `list_keybindings`（实时值），**不**从手册答（手册只写默认键） |
| C-5 | 「参数同步模式这个设置在哪一页？」 | 走 `list_settings`（它带页/行定位）；如同时引用手册解释语义可以接受 |
| C-6 | 无参调用 `get_manual`（可让它「列出手册目录」） | 返回 17 章的 id + 标题 + 子节，头部注明手册语言 |
| C-7 | 让它读一个不存在的章（如 `section=nope`） | 回报「没有匹配章节」+ 目录，模型据此改用正确 id 重试 |
| C-8 | 把 `Resources/Manual` 临时改名后重启，再问 C-1 | 工具回报手册未随包，模型如实说明手册不可用并改用自省工具，**不**编造手册内容 |
| C-9 | 界面语言设为 English 后问 C-1（手册仍只有中文） | 用**英文**作答（内容取自中文手册），不把中文原文整段贴给用户 |

## 已知边界（不是 bug）

- 手册目前只有 `zh-CN`；其他界面语言一律回退并注明。补译只需新增 `docs/user-manual.{文化码}.md` 并在 csproj 里加一条 `Link`。
- 手册窗没有全文搜索（目录跳转 + agent 检索先够用）。
- 放大浮层与 Agent 图片附件的放大是同一套实现（`ImagePreviewOverlay`），故两处手感一致；改一处即两处都变。
- 弹出层（右键菜单、详情窗）在手册里以清单形式描述，没有插图——headless 抓不到 popup 窗口。
